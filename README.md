#  BW Study Abroad Guide

A homeschooling resource platform designed to help Botswana students 
navigate the journey of studying at international universities.

##  The Problem

Many talented Batswana students want to study abroad but don't know:
- Which universities to apply to
- What qualifications are required
- How to write personal statements
- How to apply for scholarships
- How to prepare while still in Botswana

##  The Solution

This platform provides a structured, self-paced guide covering everything 
a Botswana student needs to successfully apply and prepare for 
international university education.

##  Features (Planned)

- [ ] University search by country, cost, and course
- [ ] Step-by-step application checklist
- [ ] Scholarship database for African students
- [ ] Personal statement writing guide
- [ ] Community forum for Batswana students abroad
